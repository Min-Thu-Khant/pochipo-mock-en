## 操作

| 確認 | 結果 |
| --- | --- |
| 部品検索、一致0件 | 一致する部品のみ表示、0件メッセージ表示 |
| 10pt受取 | 残高240→250、交換目標まで60→50、受取済みへ |
| 連続受取 | 操作不可となり二重加算なし |
| リセット | 初期の残高・受取状態へ |
| コイン演出 | 5枚を生成し、演出終了後にDOMから削除 |
| OSの動きを減らす | コイン移動なしでも残高更新 |
| 部品集の演出スイッチ | 埋め込みホームにも設定を反映 |
| ダイアログ | 開閉、Esc、元のボタンへの復帰 |
| 空／エラー／再試行 | 別表示、再試行後に0件の表示へ |
| ホームのカテゴリ | キーボード右矢印で次のカテゴリへ |
| 下部ナビ | 390 / 360pxでスクロール前後の位置が一致 |
| アンケートバナー | ミッションと横幅・左位置・背景色が一致 |
| 保存データ | 受取前後でlocalStorageの値に変更なし |
| 資料リンク | ページ内のMarkdownリンクがHTTP 200 |
| 実行エラー | 確認した画面にJavaScript例外・HTTPエラーなし |
