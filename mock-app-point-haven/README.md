# ポイントヘイブン 南国デザイン保存版

2026-09-28時点の南国デザインを保存したアプリモック。通常版は `../mock-app/`。リポジトリルートで `node server.mjs` を実行し、`/mock-app-point-haven/` を開く。

HTML・描画コード・素材はこのフォルダに保持する。一部の共有モジュールは通常版を参照し、同一オリジンの管理画面設定・ブラウザ保存データを共有する。単独フォルダの配布用ではない。

## ブランドデザイン検討（2026-09-28）

アプリモックでは名称を「ポイントヘイブン（Point Haven）」とした南国モチーフの案を検討する。既存のジェリー系ガイドの明度・彩度と立体表現を継承する。緑・青・赤・黄・紫・橙を用い、島、ウミガメ、熱帯魚、貝殻、ハイビスカス等の南国モチーフへ置き換える。主操作は緑、進捗は青、報酬は黄とし、犬のキャラクターは使用しない。名称と見た目の試作であり、正式な名称の確定やポイントの業務ルール変更を意味しない。

確認対象はホームのブランド表示、各タブの可読性、既存導線の維持、管理画面連動デモへの反映である。

ホーム上部のブランド帯は表示しない。ホームのアイコンは木のバンガロー、お得は宝箱、アンケートは巻物、レシートは専用のレシート画像とする。ヤシの島は簡単タブの案内部分にウミガメと合わせて使用する。

歩数カードは砂浜と波打ち際、動画カードは波と熱帯魚、アンケート導線は南国の明るい面で装飾する。歩数・達成判定・報酬額は既存の実数を維持し、装飾に進捗の意味を持たせない。

通知の装飾アイコンはヤシの木に赤いポストを組み合わせた形とする。通知の名称・未読表示・操作は変更しない。

歩数の各地点は上下交互のジグザグに並べ、Pの周囲をビーチサンダル型にする。未獲得は砂色、獲得可能は黄色、獲得済みは緑色とチェックで区別する。

デイリーミッションは木の掲示板と貼り紙をモチーフにする。進捗・ミッション一覧・もっと見るの操作は維持し、木目や留め具は装飾のみとする。

下部ナビの「簡単」は、巻き紙が入った水色の縦長で太めの、斜めに傾けたメッセージボトルで表示する。チャレンジボーナスのヒトデは維持する。

歩数地点のサンダルは、ソールの側面、鼻緒のハイライト、砂浜への影で立体感を付ける。状態色とチェック表示は維持する。

ホームの「ゲーム」カテゴリはシュノーケルのアイコンで表示する。「ミニゲー」とは別のアイコンを使用する。

ミッション掲示板は濃い茶色の木材を基調に、木目の濃淡・節・板の継ぎ目を表現する。見出しは明るい文字、内容は明るい貼り紙上に表示する。

アプリのコンテンツ背景は白（#FFFFFF）とする。砂浜色は歩数カードなどの装飾部分に限定する。

残高・報酬欄のポイントアイコンには、生成済みのPとヤシの葉を組み合わせた立体コイン素材を使用する。
