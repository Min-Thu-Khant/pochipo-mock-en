# ポイント獲得履歴

参照: [タメルコ Figma 60647:41072](https://www.figma.com/design/OxKHX6jb2qWVEOs3UkzP8W/?node-id=60647-41072)

2026-09-29取得。point / all / survey / admin のSVGとグラフ右軸の補助画像をローカル配置。グラフ・金額・履歴はアカウントのデータから生成する。画面全体の画像は使わない。

Code Connectが指すSpindle React部品はこのVanilla JSモックにないため、ヘッダー・ナビ・操作ボタン・対応する履歴アイコンには既存の共通部品を使用。画面名はユーザー指定の「ポイント獲得履歴」を維持し、既存の交換導線を残す。
