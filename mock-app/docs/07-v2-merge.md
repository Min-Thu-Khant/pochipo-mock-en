# v2 統合メモ：現状アプリのデザイン × tameruko-boost の機能

作成日：2026-09-15。現状アプリの画面キャプチャ（TOP）と、プロトタイプ `tameruko-boost` を突き合わせ、
「現状の見た目を維持しながら、プロトタイプの機能を追加した新バージョン」として再構成した。

## 現状アプリから維持したもの

| 項目 | 維持内容 |
|---|---|
| 配色 | ティール基調（主操作・アイコン）、白カード、薄いミント地、ライム色の強調（受け取るボタン・無料タグ・進捗バー） |
| ヘッダー | 左に残高ピル（Pコイン＋数値）、右にお知らせアイコン |
| デイリーミッションカード | 緑のカード、「今日の進捗 n/N」バー、行ごとに「受け取る／やってみる」ボタンと報酬バッジ。ファーストビュー確保のため日付・曜日・マスコットは外し、見出しは「デイリーミッション」のみ。既定は折りたたみ（進捗・今日できるお仕事の件数・見込み額・受け取り可能件数）、見出し右の「ミッションを見る」で展開 |
| TOPのセクション構成と順序 | 歩いてためる（コンパクト・最上部）→ デイリーミッション → 広告枠（640×100）→ 特集枠 → あなたにオススメ（3列グリッド）→ 高額案件の行 → お得な買い物 → チャレンジボーナス → アンケートでためる → 動画を見てためる → 横スクロールの案件枠 → MREC |
| 歩いてためる | 今日の歩数、1,000歩ごとのマイルストーン、「獲得する」ボタン。ファーストビュー確保のため2行のコンパクトなカードにし、マスコットと吹き出しは外してホーム最上部へ移動 |
| 動画を見てためる | 「再生する」ボタン、1回あたりの報酬 ×3、受取スタンプと n/3 |
| 案件カード | ロゴタイル、案件名、Pコイン＋金額、ライムの「無料」タグ、横スクロール |
| フッター | ホーム／ためトク／マイページの3タブ |

## プロトタイプから追加したもの

| 機能 | 置き場所 |
|---|---|
| 円相当の残高表示、確認中（仮付与）残高、累計 | ヘッダーの残高ピル、マイページ、内訳ダイアログ |
| 今日できるお仕事の件数・獲得見込み額 | ミッションカードのフッター →「今日できること」一覧 |
| 期間限定UP・ブーストのキャンペーン枠（運用枠・期間・優先度・セグメント） | TOPの特集枠（旧「ポイ活タイプ」枠の位置）、グリッドの「期間限定UP」バッジ、通常価格の取り消し線 |
| 事前エントリー制の案件 | 案件詳細の注意文・ステップ・CTA「エントリーする」 |
| みんなでチャレンジ（達成人数・追加ボーナス） | 案件詳細（ガーデンパズル） |
| マイ案件（取り組み中／獲得済みタブ、段階進捗、問い合わせカード） | ためトクのサブタブ、マイページ、TOPの「参加中の案件」 |
| アンケート一覧・事前調査→本調査の案内・プロフィール登録 | TOP「アンケートでためる」→ 一覧 → 回答 → 完了 |
| 動画の日次上限とアンケートへの誘導 | 動画セクション・ミッション行・ダイアログ |
| 保留（確認中）→承認の流れ | デモ設定「回答後に確認中」→「確認中の報酬を承認する」 |
| 読み込み中・取得エラー・0件・掲載終了の状態 | デモ設定「画面の表示状態」 |
| お知らせ、今日の実績カード（SVG保存）、交換手数料0円の説明 | ヘッダー、マイページ、TOP下部 |
| 通常成果とAF報酬のミッション化（期間限定案件が日次ミッションに並ぶ） | ミッションカード最下行（PR表記） |
| 起動時ポップアップバナー（運用枠の placements に `popup` を持つ枠を優先度順に表示。1日1回が既定） | ホーム起動時。デモ設定「起動時ポップアップの表示」（1日1回／毎回／表示しない）、「表示する枠」、「起動時ポップアップを表示する」、「本日の表示済みをリセット」 |
| テキストバナー（ピル形状・横スクロール）：運用枠 kind `ticker`／placements `pill`。表示期間・優先度・セグメントは他の枠と共通。リンク先は案件・カテゴリ・チャレンジ一覧 | ためトクの検索窓の下 |
| チャレンジボーナス（モッピー同型の座組）：運用枠 kind `challenge`。期間内に対象案件の参加人数（`participants`）が目標（`challengeGoal`）に達すると、参加者全員（達成後の利用者も含む）に通常報酬とは別の `bonus` を付与。ボーナスは通常報酬の承認後に付与（`settleChallenges`）。否認は対象外、目標未達はボーナスなし | ためトク「チャレンジボーナス」枠（3列グリッド：通常報酬・参加人数メーター・残り日数・達成で+○円相当）→ 一覧ページ（しくみ説明付き）、TOP、案件詳細のチャレンジ枠とCTA「チャレンジに参加して利用する」、マイ案件の達成待ち／付与予定／付与済み表示。デモ設定「参加人数を+500人」「達成にする」 |

参考：モッピー「[チャレンジボーナスとは](https://pc.moppy.jp/campaign/challenge/guide.php)」「[ヘルプ](https://pc.moppy.jp/help/?category_id=15)」の公開説明（目標人数達成で参加者全員にボーナス、達成後の利用者も対象、承認翌日に付与、否認は対象外、予算超過で早期終了の可能性）を座組の参照とした。

## 2026-09-15 追記：spec 準拠の修正

数値・条件・文言は GitHub の poikatsu-spec を優先して修正した。反映内容と仮値の一覧は [08-spec-gap.md](08-spec-gap.md) の 9 章を参照。

## 2026-09-15 追記：ホームの改修

- **最上部バナー枠**（Braze `home_first` 相当）：運用枠の表示位置「ホーム最上部バナー」。優先度が最も高い 1 枚を表示し、配信対象外はトルツメ。タップでディープリンク `feature/<id>`（特集ページ：案件の集約または 1 案件の特集）へ遷移。特集ページと枠は管理画面モックで作成・編集する。
- **デイリーミッション**：「アプリを開こう」「歩いてためよう」「動画を見てためよう」の未クリア分のみ常時表示（最大 3 件）。クリア済みと、その他のタスク（アンケート・期間限定案件）はアコーディオン「クリア済み・その他のミッション」に収納。全体の折りたたみボタンは廃止。

## 2026-09-15 追記：ホームの並び替えとタイルメニュー

- **カテゴリのタイルメニュー**：「あなたにオススメ／期間限定UP・注目の案件」の上に 4 列のタイルを表示。中身は案件画面設定の画面コード `home_quick`（管理画面で入稿。カテゴリのほか `challenges` / `surveys` / `mycases` を指定すると各一覧へのリンク）。
- **並び**（2026-09-15 最終）：最上部バナー → デイリーミッション → **アンケートでためる** → Braze home_second → 特集枠 → **タイルメニュー** → チャレンジボーナス → 動画 → あなたにオススメ → 高額 → お得な買い物 → マイ案件 → スタッフのおすすめ → アプリでためる → 交換 → **歩いてためる（最下部）** → MREC。
- ヘッダー右のマイ案件アイコンは分かりにくいため削除（spec のヘッダー常設導線とは差分。マイ案件はためトクのサブタブ・タイルメニュー・マイページから到達）。
- 「歩いてためよう」の「やってみる」は最下部の歩いてためるへスクロールする。

## 2026-09-15 追記：ためトクの整理

- 「獲得までの流れ」はサブタブから外し、ヘッダー右の「？」アイコン（タップでポップアップ）に変更。サブタブは「おすすめ／マイ案件」。
- 検索窓の上のアイコンメニュー（クイックアクセス）は、検索窓の下のカテゴリチップと機能が重複するため削除。カテゴリチップは案件画面設定 `tametoku_quick` から生成する（spec のためトクナビ／クイックアクセスの 2 段構成とは差分）。

## 判断が必要な点

- **ポイ活タイプ診断**：新方針（診断なし）に従い、旧「ポイ活タイプ」枠の位置をキャンペーン枠に置き換えた。診断を残す場合は特集枠の2枚目以降として併存できる。
- **金額表記**：現状アプリの「P」表記と新方針の「円相当」を両立させるため、Pコイン＋数値＋「円相当」の組み合わせにした。内部は100pt=1円相当。
- **タブ構成**：プロトタイプの4タブ（アンケート・マイ案件を独立）ではなく、現状の3タブを維持。アンケートはTOPから、マイ案件はためトクのサブタブとマイページから到達する。
- **歩数・起動ミッション**：現状アプリに存在するためモデルに追加した（歩数SDKは未接続、デモ設定で歩数を進める）。
- **チャレンジボーナスの参加**：モッピーは「このチャレンジに参加する」ボタンで参加を明示する。本モックでは案件の利用開始（既存のエントリー→利用フロー）を参加とみなし、利用開始時に参加人数を+1している。参加ボタンを分ける場合は `startOffer` の前段にエントリー相当の操作を追加する。
- **ロゴ・マスコット**：実際のロゴ画像・キャラクター素材は含めていない。色付きタイルと簡易SVGマスコットで代替。
