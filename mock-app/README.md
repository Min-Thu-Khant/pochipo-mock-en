# タメルコ v2 モック（現行デザイン × 新機能）

## 2026-10-02：アプリモックの更新

- 「今月の獲得見込み」・獲得目標の試作は含めていません。
- ポイント残高・失効予定・履歴、毎回のSMS確認を挟むドットマネー交換フローを反映しました。デモSMSコードは `123456` です。
- 会員情報、SUR段階進捗、アンケートの回答完了後の付与、ミッション表示、動画報酬後の初回ATT案内を更新しました。
- 戻る操作では、直前のページの選択状態・展開状態・スクロール位置を復元します。
- 管理画面との共有設定・成果データを読み取る処理を含みます。各管理画面の新しいUIは別途反映します。

本番の認証・SMS・広告SDK・送金・プッシュ配信には接続していません。ミッション独自の追加ボーナスは未確定のため、無効のままです。

現状アプリの見た目（ティール基調・デイリーミッションカード・3タブ・横スクロール枠）を維持しながら、
プロトタイプ `tameruko-boost` の機能（円相当残高・期間限定ブースト・チャレンジ・マイ案件・アンケート連鎖・状態表示）を統合したスマホ向けWebモックです。架空のデータを使用します。

## 開く・起動する

リポジトリのルートで `npm start` → http://localhost:4173/mock-app/ （管理画面モックは /mock-admin/ 。同一オリジンで状態を共有）。このディレクトリ単体でも `npm start` で起動できる。依存パッケージ不要、Node.js 20以上。
`index.html` を直接開いても動作します（ES Modulesのため、ブラウザーによってはローカルサーバー推奨）。

## Figmaのダイアログ（2026-09-24）

新規データは歩数の未許諾状態で始まり、歩数タブを開くとOSに合った許諾案内が自動表示される。既存データで試す場合は「デモ設定」→「歩数計測の連携」を「未許諾」に変更する。拒否・閉じるでは許可扱いにせず、許可後は案内を出さない。対象はヘルスケア／身体活動の許諾で、GPS位置情報は取得しない。

「表示・動作の確認」→「ダイアログ一覧（14種類）」から指定Figma周辺の全14種類を表示できる。狭い画面では「デモ設定」を開く。URLに `?dialog=step-select` や `?dialog=ad-empty` を付けても表示できる。表示確認ではポイントや権限を変更しない。

歩数受取・動画視聴・権限案内・検証用の日付変更にも接続済み。実際の報酬額は管理設定を使用する。検証設定の「次の動画視聴で再現するエラー」は1回だけ適用される。[反映内容・達成条件・確認上の制約](../docs/prd/app-requirements/dialog-update-20260924.md)を参照。

## お知らせ

ベルを押すと「キャンペーン」「お知らせ」の2タブが開く。キャンペーンから案件・特集へ遷移し、お知らせから不具合・アップデート等の本文を開ける。運営情報はサンプル。[F17の更新仕様](../docs/prd/app-requirements/notification-update-20260924.md)。

## 赤ポチ

ホームのポイント増加、歩数の受取可能、カテゴリの新着、ミニゲーの残回数、お得のテキストバナーとマイ案件の更新を赤ポチで案内する。新着は該当一覧、ポイントは履歴、テキストバナーはリンク、マイ案件は対応するステータスを確認すると消える。歩数・ミニゲーは行動可能な間残る。既読はブラウザーに保存する。[表示・消灯条件](../docs/prd/app-requirements/attention-update-20260924.md)。

## 画面

- **ホーム（TOP）**：上部に 8 つのカテゴリタブ（案件画面設定 `home_tabs` で入稿。PR #1）。デイリーミッションタブ＝最上部バナー・ミッションカード（基本 3 種＋クレカ閲覧を常時表示、クリア済み・その他はアコーディオン）・動画・アンケート CTA。歩数／チャレンジ／ゲーム／買い物／アンケート／チャット／クレカの各タブ。カテゴリ広告は運用枠から表示。以下は PR #1 以前の構成：広告枠、キャンペーン特集枠、あなたにオススメ、高額でためる、歩いてためる、お得な買い物、アンケートでためる、動画を見てためる、参加中の案件、スタッフのおすすめ、アプリでためる、交換手数料0円、MREC。
- **今日できること**：今日のタスクと見込み額の一覧。
- **目減りゼロ表示（新規提案）**：ヘッダー残高の下に「手数料10%の場合」の試算額を取り消し線で表示、「手数料 0 円」バッジ→説明シート、マイページの交換レシート（小計／手数料 ¥0／レート／受取額）。デモ設定でオン／オフと比較率を変更。
- **探す**（旧ためトク）：おすすめ／マイ案件、検索、テキストバナー（ピル）、カテゴリチップ、チャレンジボーナス枠、案件カード。ヘッダーの「？」で獲得までの流れ。
- **高還元／すぐできる／友達招待**（PR #1）：案件の抽出一覧とカテゴリ広告、友達招待のモック（紹介コードのコピー）。
- **チャット**（PR #1）：選択式の分岐でおすすめ案件に到達するチャットアンケート（ホームのタブ）。
- **チャレンジボーナス一覧**：開催中のチャレンジ（参加人数メーター・残り日数・達成で+○円相当）としくみの説明。
- **案件詳細**：期間限定UP、事前エントリーなしの参加、みんなでチャレンジ、獲得までのステップ、注意事項、固定CTA。
- **マイ案件**：取り組み中／獲得済み、段階進捗（Lv.5/10/17）、問い合わせ案内。
- **アンケート**：一覧、プロフィール登録、事前調査→本調査、回答・中断・送信・完了。
- **マイページ**：残高・確認中・累計、交換条件、履歴、メニュー、設定行。

## 2026-09-15：poikatsu-spec に合わせた修正

数値・条件・文言は GitHub の仕様書（poikatsu-spec）を優先しています。合算ポイント／準備中／交換可能、付与予定→自動判定・有人審査、ミッションの達成と受け取りの分離、歩数の 1 回 1 マイルストーンと獲得方法選択、動画の配信可否・再生済み、チャレンジする／成果ステータス 4 種、最低交換 100pt、アンケートの還元率換算など。仕様書が運用設定としている値（歩数 1,000 歩 × 4 回、動画 3 回、各ポイント額、還元率）は仮値で、デモ設定パネルに表示しています。詳細は [docs/08-spec-gap.md](../docs/references/legacy-spec-gap.md) の 9 章。

## 試せる操作

1. ミッションカードの「アプリを開こう」の「受け取る」→ 獲得完了ダイアログ → 準備中（付与予定）に登録。クリア済みは「クリア済み・その他のミッション」のアコーディオンに移る。
0. 最上部バナー「秋のおでかけ特集」をタップ → 特集ページ（案件の集約）。管理画面の「特集ページ」「運用枠」で差し替えできる。
2. 「歩いてためる」の「獲得する」→ 獲得方法選択（動画あり／なし）→ 1 マイルストーン獲得 → ミッション「歩いてためよう」が達成済みになり「受け取る」が出る。
3. 「動画を見てためる」→ 再生 → 獲得。3 回で「再生済み」「本日分終了 3/3」。デモ設定「未成年（広告配信なし）」でセクションとタスクが消える。
4. 案件詳細 →「チャレンジする」→ 確認シート → マイ案件「判定中」（SUR は「挑戦中」）。デモ設定「成果を承認」→「承認」タブと付与予定（審査）。「有人審査で承認」で交換可能へ。
5. アンケートに回答 → 準備中に登録 → デモ設定「ポイント自動判定を実行」で交換可能へ → 本調査の案内。
6. マイページで合算・準備中・交換可能・交換状態テキスト（3 状態）を確認。デモ設定「ゲスト」で会員登録訴求に切り替わる。
7. デモ設定「歩数計測の連携：未連携／利用不可」で歩数カードの状態を確認。
8. チャレンジボーナス：ホームの「チャレンジボーナス」タブまたは探すのチャレンジ枠 →「チャレンジする」→ 承認 → デモ設定「達成にする」でボーナスが付与予定に登録。
9. テキストバナー：探すの検索窓の下のピル。
10. 起動時ポップアップ：デモ設定「表示する枠」→「起動時ポップアップを表示する」。

状態はブラウザーのlocalStorageに保存され、「デモ設定」→「デモデータを初期化」で戻せます。
