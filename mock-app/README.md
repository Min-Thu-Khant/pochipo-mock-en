# タメルコ v2 モック（現行デザイン × 新機能）

現状アプリの見た目（ティール基調・デイリーミッションカード・3タブ・横スクロール枠）を維持しながら、
プロトタイプ `tameruko-boost` の機能（円相当残高・期間限定ブースト・エントリー・チャレンジ・マイ案件・アンケート連鎖・状態表示）を統合したスマホ向けWebモックです。架空のデータを使用します。

## 開く・起動する

このディレクトリで `npm start` → http://localhost:4173/ 。依存パッケージ不要、Node.js 20以上。
`index.html` を直接開いても動作します（ES Modulesのため、ブラウザーによってはローカルサーバー推奨）。

## 画面

- **ホーム（TOP）**：残高ピル、デイリーミッション（起動・歩数・動画・アンケート・期間限定案件）、広告枠、キャンペーン特集枠、あなたにオススメ、高額でためる、歩いてためる、お得な買い物、アンケートでためる、動画を見てためる、参加中の案件、スタッフのおすすめ、アプリでためる、交換手数料0円、MREC。
- **今日できること**：今日のタスクと見込み額の一覧。
- **ためトク**：おすすめ／マイ案件／獲得までの流れ、カテゴリのクイックアクセス、検索、テキストバナー（ピル）、チャレンジボーナス枠、案件カード。
- **チャレンジボーナス一覧**：開催中のチャレンジ（参加人数メーター・残り日数・達成で+○円相当）としくみの説明。
- **案件詳細**：期間限定UP、エントリー制、みんなでチャレンジ、獲得までのステップ、注意事項、固定CTA。
- **マイ案件**：取り組み中／獲得済み、段階進捗（Lv.5/10/17）、問い合わせ案内。
- **アンケート**：一覧、プロフィール登録、事前調査→本調査、回答・中断・送信・完了。
- **マイページ**：残高・確認中・累計、交換条件、履歴、メニュー、設定行。

## 2026-09-15：poikatsu-spec に合わせた修正

数値・条件・文言は GitHub の仕様書（poikatsu-spec）を優先しています。合算ポイント／準備中／交換可能、付与予定→自動判定・有人審査、ミッションの達成と受け取りの分離、歩数の 1 回 1 マイルストーンと獲得方法選択、動画の配信可否・再生済み、チャレンジする／成果ステータス 4 種、最低交換 100pt、アンケートの還元率換算など。仕様書が運用設定としている値（歩数 1,000 歩 × 4 回、動画 3 回、各ポイント額、還元率）は仮値で、デモ設定パネルに表示しています。詳細は [docs/08-spec-gap.md](docs/08-spec-gap.md) の 9 章。

## 試せる操作

1. ミッションカード（既定は折りたたみ）の「ミッションを見る」で展開 →「アプリを開こう」の「受け取る」→ 獲得完了ダイアログ → 準備中（付与予定）に登録。
2. 「歩いてためる」の「獲得する」→ 獲得方法選択（動画あり／なし）→ 1 マイルストーン獲得 → ミッション「歩いてためよう」が達成済みになり「受け取る」が出る。
3. 「動画を見てためる」→ 再生 → 獲得。3 回で「再生済み」「本日分終了 3/3」。デモ設定「未成年（広告配信なし）」でセクションとタスクが消える。
4. 案件詳細 →「チャレンジする」→ 確認シート → マイ案件「判定中」（SUR は「挑戦中」）。デモ設定「成果を承認」→「承認」タブと付与予定（審査）。「有人審査で承認」で交換可能へ。
5. アンケートに回答 → 準備中に登録 → デモ設定「ポイント自動判定を実行」で交換可能へ → 本調査の案内。
6. マイページで合算・準備中・交換可能・交換状態テキスト（3 状態）を確認。デモ設定「ゲスト」で会員登録訴求に切り替わる。
7. デモ設定「歩数計測の連携：未連携／利用不可」で歩数カードの状態を確認。
8. チャレンジボーナス：ためトクのチャレンジ枠 →「チャレンジする」→ 承認 → デモ設定「達成にする」でボーナスが付与予定に登録。
9. テキストバナー：ためトクの検索窓の下のピル。
10. 起動時ポップアップ：デモ設定「表示する枠」→「起動時ポップアップを表示する」。

状態はブラウザーのlocalStorageに保存され、「デモ設定」→「デモデータを初期化」で戻せます。
