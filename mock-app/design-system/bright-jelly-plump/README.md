## 内容

15種類の部品・基準（アイコン16点）：配色、アイコン、文字、ボタン、選択チップ、残高と交換目標、ミッション状態、進捗、歩数、週の記録、達成ダイアログ、ヘッダー／フッター、案内バナー、案件／アンケートカード、読み込み／空／エラー。

通常版のファイルは変更せず、このフォルダに実装・素材・説明を追加しています。既存の共通HTML部品を読み込み、`tokens.css` と `theme.css` を検討版だけに適用します。週の記録などの新しい部品は候補として掲載し、ホームへ一律には追加しません。

## 元の素材

- ユーザー指定の `pochipo/output/imagegen/bright-jelly-v1` のPNG4点を `assets/` にコピー。追加12点は `assets/jelly-v2/` に保存。元の4点は画像加工なし。
- 元の生成プロンプト：[asset-prompts.md](references/asset-prompts.md)。参考パレットの英語画像は表示せず、CSSと日本語HTMLで色見本を作成。
- 調査資料：[ui-motivation-references-2026-09-18.md](references/ui-motivation-references-2026-09-18.md) を複製。
- 添付されたDuolingoの6枚のスクリーンショットを視覚参考として閲覧。画像やキャラクター自体の転載はしていません。

## 試作の範囲

ホームはヘッダー、8カテゴリ、特集、ミッション、中間バナー、動画、アンケート導線、固定4メニューの順を維持。カテゴリ名・並びは既存 `homeTabsFor(initialState())`、ミッション行と進捗、カード、フッターは既存共通部品を利用します。

受取時の残高はメモリ内の見本値のみ更新し、リロードまたはリセットで戻ります。既存モックの保存データや管理画面には書き込みません。案件・アンケートの回答処理、広告配信、審査・交換などには接続していません。
