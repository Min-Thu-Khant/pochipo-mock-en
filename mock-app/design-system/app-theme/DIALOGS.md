# ダイアログ仕様

新デザインの部品集用。既存アプリの業務処理・OS権限・広告表示・ポイント付与は変更しない。

| ID | 用途 | 操作 |
|---|---|---|
| PG-D01 | 未保存内容の破棄確認 | 編集を続ける／破棄する |
| PG-D02 | 節目の獲得完了 | 閉じる |
| PG-D03 | 通信・読込エラー | 再読み込み／閉じる |
| PG-D04 | OS権限の事前説明 | 設定を開く／あとで |
| PG-D05 | 報酬の選択 | 動画視聴／通常受取 |
| PG-D06 | 処理中 | 二重操作を無効化 |

幅最大342px、左右16px以上、角丸16px、内側16px。見出し18px/600、本文14px、アイコン40px。ボタン48px以上、縦間隔8px。主操作は緑、副操作は白、破棄文言は赤。モバイルでは長文の本文を左揃えにする。

native dialogを使用し、aria-labelledby/aria-describedbyを対応。閉じた際は起点にフォーカスを戻す。通常はEscで閉じる。背景クリックで閉じない。多重表示は禁止。破棄確認は安全な操作を初期フォーカスにする。

処理中はダブルクリック防止を機能側で実装する。中断可否は対象処理の仕様で決める。閉じただけで通信キャンセルや報酬確定とみなさない。無期限の待機は避け、タイムアウト時の案内と再確認を用意する。見本は閉じる操作を追加しており、本番の処理状態を再現するものではない。

通常の成功はトースト／画面内表示を優先。エラーは原因と次にできる操作を示す。ユーザーの入力は保持する。数値・選択条件はアプリの実データを渡し、部品見本の値を流用しない。

実装：dialog-components.js / dialogs.css / dialog-catalog.js。アプリへの適用時は既存dialogs.jsのdata-actionと状態遷移を維持する。
