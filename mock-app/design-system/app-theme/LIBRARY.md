## 今回の範囲

現行アプリを出発点に、ユーザー指定の単色コーラル・均一線幅アイコン・タメルコのタイポグラフィと部品構成を適用した、ブラウザーで確認できる独立した部品集。アプリ本体の業務処理・報酬条件・保存データは変更しない。Figma上へのコンポーネント作成は今回の成果物に含まない。

ユーザーの追補により、デイリーミッションは「活動が完了すると自動で済み」を維持する。丸いバッジと「やってみる／済み」の2状態を用意し、手動の「受け取る」を挟む見本は撤回した。実アプリにも同じトークン・アイコン・ミッション部品を組み込む。

## ファイルと再利用

| ファイル | 役割 |
| --- | --- |
| library.html / library.js / library.css | 目次・検索・操作可能な見本 |
| library-components.js | ボタン・報酬・ミッション・案件カード・エラー表示の描画関数 |
| mission-components.css | 丸いバッジ、未完了／完了の状態色と配置 |
| library-tokens.css | 今回の配色案 #FF7A70、文字・丸みの役割別トークン。アプリ本体と共用 |
| library-icons.js | chat・homeの輪郭を基準にした均一2pxのSVG。game等は細部を簡略化 |
| ../../point-symbol.js | アプリと共用するP記号 |

`library-components.js`の可変テキストはエスケープする。`attrs`は開発者が作る信頼済みのテンプレート属性だけを渡し、ユーザー入力を渡さない。表示用関数に報酬付与・認証などの業務処理を持たせない。

```js
import { missionRow, missionAction, missionBadge } from './library-components.js';
missionRow({ name: '歩いてためよう', ico: 'walk', state: 'todo', amount: 100 });
missionAction('claimed'); // disabled の「済み」
missionBadge('walk', 'claimed'); // 達成を示す丸いバッジ
```

`library.css`は部品集のページ用CSSを含むため、アプリへ丸ごと読み込まない。組み込む場合は対象部品のスタイルだけを取り出し、既存画面と確認する。

## 動作と制約

検索、チップ、タブ（左右キー／Home／End）、下部ナビ、バナードット、入力エラー、折りたたみ、ダイアログ、トースト、エラー切替、広告の読み込み切替、ミッションの自動完了デモを用意した。見本の設定は保存せず、実アプリのlocalStorageにはアクセスしない。

画面幅650px以下は1列表示。ミッションの狭幅は390px以下でアイコンと余白を調整。色以外にラベル・disabled・aria属性で状態を示す。

## 2026-10-07 デザイン調整

- 基調色は添付の右下の丸に近い `#FF7A70`。画像からの目視近似で、厳密な指定値ではない。グラデーションなし。淡色はメインを白で薄め、操作ラベルは濃い色を使う。
- 文字はタメルコiOSのヒラギノ角ゴ W3（300）／W6（600）。見出し140%、本文160%、ボタン130%。12・13・14・15・16・17・18・20pxの比較を掲載。Windows等でヒラギノが利用できない場合はNoto Sans JP等へフォールバックする。
- 通常ボタンは大48px／中40px／小32px。左右余白16px（小10px）、文字16／14／13px。角丸は高さの半分以上（CSS 999px）で、両端が丸いピル型。枠線・淡色・無効も同じ形にする。長い文言は折り返して高さを伸ばす。
- アイコンは24pxグリッド・線幅2pxで内部線も統一。丸い線端・接合部。gameは十字キーとボタン1個、カード・カレンダー・レシートは内部線を減らす。PNG原本への加工ではなく、現在のSVGの輪郭を基にしたアプリと部品集で共用するベクター。原本ファイルは保持する。
- デイリーミッションの報酬はP記号＋数値のみ。末尾のptを表示しない。活動の完了で自動的に「済み」へ変わる挙動を維持する。

- 2026-10-07 追加比較：メインカラーボタン（ポイントゲット等）の文字・内側アイコンを白に変更。背景は #FF7A70 を維持。淡色・枠線・無効ボタンの文字色は変更しない。

## 2026-10-07 アプリ適用

アプリ本体は `library-tokens.css` と `mission-components.css`、既存画面への接続用 `app-components.css` を使用する。主操作は単色コーラル＋白文字、タブ選択色とP記号も共通色。認証プロバイダーのブランド色、エラーなどの意味色は維持する。歩くアイコンは4187版と同じ靴の線画SVGを共用。ミッションは初期5件・完了項目を下へ・展開状態と遷移先を維持し、報酬のみP＋数値へ変更する。

## 2026-10-07 文字指定の統一

アプリの各CSSに残る数値直書きの太さをW3/W6トークンに移行し、サイズも共通スケールを参照する。通常の文字階層は12〜20px、残高・獲得ポイント等の強調数値には別の大きい数値スケールを使用する。マイページは残高32px・内訳20px・見出し16px・本文14px・補足12px。枠線ボタンは最新指定により白背景＋コーラル文字・枠線に統一する。広告画像内の文字やプロバイダーのブランド表現はアプリ本文の文字指定とは区別する。

## ポイント単位と強調ナビ（2026-10-07）

| 場面 | 表記 | 部品 |
| --- | --- | --- |
| デイリーミッション・動画の報酬 | P記号＋数値。ptなし | `activityReward(amount)` |
| アンケート一覧の報酬 | 黄色いP記号＋数字の範囲のみ（例：P 210~2,100）。ptは付けない | `surveyItem({min,max,...})` |
| ヘッダー・マイページの残高、履歴、案件詳細 | P記号＋数値＋pt（内訳は数値＋pt） | `reward(amount)` |
| 文章・ボタンなどP記号がない場所 | 数値＋pt | 例：動画を見て200ptを受け取る |
| 還元率・円換算 | %・¥・円相当 | ポイント単位と混同しない |

数値は3桁区切り。おすすめサイドタブと簡単ナビは、取得済みGit main `a8797ce` の `#D96F4B → #FF3B62` 縦グラデーションへ戻す。この2つは通常CTAの単色ルールの例外。「受け取らずに再挑戦」は追補により白背景＋コーラル文字・枠線にする。この配色を枠線ボタン全体の共通ルールへ採用する。

## 枠線ボタンの共通ルール（2026-10-07）
