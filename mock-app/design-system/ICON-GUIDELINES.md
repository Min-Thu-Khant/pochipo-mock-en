## 1. Figmaで確認したルール

### 線の種類ごとの太さ

24×24のアイコン例を基準とする。

| 線の種類 | Regular | Bold |
| --- | --- | --- |
| 1〜2本の線（1–2 Line） | 2px | 3px |
| 円形の線（Circle Line） | 2px | 2.5px |
| 四角形の線（Rectangle Line） | 2px | 2.5px |
| 内側の線（Inner Line） | 1.5px | 2px |

すべてのパーツを同じ太さにしない。内部の細部は外形より細くする。
参照：22391:38835。

### 中心線を基準にする

線の太さをx、角度をθとしたとき、角丸の中心線半径rは次の式。

```text
r(θ, x) = (3 / √2) × x × sin(θ / 2)
0° < θ < 180°
θ = 90° のとき r = 1.5 × x
```

- 半径は線の中心で測る。塗りの外端や内端の半径と混同しない。
- 90°の角で線幅2pxなら中心線半径3px。外端半径4px、内端半径2px。
- 線幅2.5pxなら中心線半径3.75px。
- 鋭角ほど半径は小さく、鈍角ほど大きくなる。
- 角度別の図にある3 / 2.5 / 2 / 1pxは見た目のパターン例として参照。生成時は上の一般式を使い、区間ごとの固定半径に置き換えない。

参照：22391:38836、22391:38837、22391:38838、22391:38839。

### 配色の展開

Figmaは `Single Color` / `Mono Color` / `Multi Color` の3タイプを想定している。
参照：22391:38556。これは3種類すべてをアプリに使う指示ではない。

## 2. ぽちぽ（仮）で採用する方針

以下はFigma原本の値とは区別した、このモックの方針。

- 通常はSingle Color、ダークグレー `#4B5552`。濃色面では白。
- 緑の差し色、アイコン背面の色付きタイル、影、グラデーション、3D表現を追加しない。
- 基準24px。通常の表示は22px、ミッション行は33px、ヘッダーのダイスは22px。
- 全体を比例拡大し、線幅・丸み・目の位置の比率を維持する。
- 小さいサイズでも意味が伝わるよう、輪郭と内部要素に十分な余白を取る。
- 操作領域と絵の大きさを区別する。アイコンが22pxでもクリック領域は小さくしない。
- 既存のFigma原本SVGは変更しない。必要に応じてマスクで単色表示する。

## 3. 今後の生成方法

1. `icons.js` と原本一覧で、既存素材がないか確認する。
2. 既存素材がある場合はそれを再利用する。
3. 新規の線画は、この数値を使うSVGなど再生成可能な形式を優先する。
4. 作る形を線・円・四角形・内部要素に分け、それぞれの線幅を決める。
5. 中心線半径を `iconCornerRadius()` で計算する。
6. 出力先、基準グリッド、線幅、角度、半径、色、生成方法を記録する。
7. 22 / 24 / 33pxと、必要なら拡大表示で既存アイコンと並べて確認する。
8. `icons.js`へ登録し、部品集のF-03または該当機能の見本に追加する。

画像生成AIを使う場合も、この線幅・半径・単色・背景透過の条件をプロンプトに含める。ただし数値どおりの幾何形状は保証されないため、出力を検証する。原本由来・新規作成・AI生成を混同しない。

### AIへ渡す追加指示

```text
アイコンを生成する前に mock-app/design-system/ICON-GUIDELINES.md と
icon-logic.js を読み、既存の原本素材が利用できるか確認してください。
原本がない場合は24px基準、Regular/Boldの種類別線幅、
r=(3/√2)×x×sin(θ/2) による中心線半径を使って設計してください。
ぽちぽはSingle Color、背景透過、影・グラデーションなしです。
原本のコピーか、新規拡張かを明記し、採用した数値と生成方法を保存してください。
```

## 4. 新しいダイス v2

Figmaにあるダイスの複製ではなく、取得したロジックに従った新規拡張。
旧imagegen PNGは履歴として残し、現在のアプリでは使用しない。

| 項目 | 値 |
| --- | --- |
| 形式 | SVG、背景透過 |
| 基準 | 24×24、正面の角丸四角形 |
| 外枠中心線 | x=3, y=3, 幅18, 高さ18 |
| Regular | 外枠2px、中心線角丸3px |
| Bold（比較用） | 外枠2.5px、中心線角丸3.75px |
| 目 | 塗りの円。直径Regular 1.5px / Bold 2px |
| 目の配置 | 7.5 / 12 / 16.5px の位置から各面を構成 |
| 色 | #4B5552 |
| バリエーション | Regular / Bold × 1〜6の目 |
| 現在の採用 | Regular。ヘッダーは5の目、抽選画面は1〜6 |

目の直径に内部線幅の値を当てること、余白、目の配置は今回の設計判断であり、Figmaに記載されたダイス仕様ではない。

```sh
node scripts/generate-dice.mjs
```

- 計算・生成元：[icon-logic.js](icon-logic.js)
- 再生成スクリプト：[generate-dice.mjs](../../scripts/generate-dice.mjs)
- 出力：[dice-v2](../assets/generated/dice-v2/)
- テスト：[icon-logic.test.mjs](../tests/icon-logic.test.mjs)

生成画像APIは使用せず、参照元の数式から決定的に生成しています。
