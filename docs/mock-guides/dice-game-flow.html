分岐を読む際のポイント

  • 回数は抽選実行時だけ消費。動画の視聴・中断・受取・ホーム移動では減りません。
  • 前の当たりが消えるのは、次の抽選を実行した時。再挑戦の選択画面を開いただけでは保持されます。次も当たった場合も合算せず、最新の1件で置き換わります。
  • 開始前動画と受取動画は別。確率アップで当たった場合、受取のためにもう一度動画を見ます。確率アップは選択した1回の抽選だけです。
  • ホームへ移動しても当たりは保持。抽選演出中の移動でも、結果は既に保存済みです。戻ると当たりを復元し、ハズレなら開始画面になります。
  • 3回目に当たった場合も受取可能。残回数0では再挑戦ボタンが出ません。翌日は残回数が3に戻り、前日の未受取当たりは削除されます。
  • 日付が変わったら前日の未受取当たりは消去。受取動画の途中でも前日の当たりは付与しません。受取済みのポイントは削除しません。
  • 動画中に日付が変わると中断扱い。当日なら同じ未受取結果でやり直せますが、翌日には失効します。受取完了後は「準備中」のポイントへ登録されます。

まだ決める必要がある分岐

  • 広告在庫なし・未成年などで受取動画を再生できない場合：当日中の代替受取を認めるか、再試行のみか。
  • 運営が途中でゲーム停止した場合：既存の未受取当たりの受取だけは許可するか。
  • 翌日失効の通知：消去した事実を案内するか、開始画面だけに戻すか。
  • 複数タブ・端末が同時に受け取る場合：本番サーバーでの排他・二重付与防止の方式。ローカルモックの連打防止とは別に扱う。
