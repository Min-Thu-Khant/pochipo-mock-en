# 起動時・タブ切り替え時の広告デモ

## 操作する場所

管理画面「バナー&テキスト広告」から配信枠を選択する。

- ホーム枠 → チャレンジボーナス上部：320×100。初期広告は星ねこクエスト。
- 起動時枠 → POPUPメイン：300×250。起動ごと／1日1回／表示しないを設定する。
- タブ切り替え時枠 → インステ広告：300×250。配信状態、切り替え回数、最短間隔、起動中の上限を設定する。

各枠で画像アップロード、遷移先URL、掲載期間、公開／停止、新規登録・編集ができる。全画面広告は1設定1枚、候補が複数なら均等に1枚を選ぶ。配信中の候補がなければ表示しない。チャレンジ上部は複数登録時にカルーセルとなる。

## 初期の表示ルール

起動時POPUPはホームでの起動ごと。インステ広告は異なるタブへの切り替え3回ごと、前の広告から30秒以上、1起動中3回まで。両方とも直ちに閉じられる。最短間隔が過ぎても自動で割り込まず、次のタブ切り替えで表示する。

上部・下部タブと「お得」のサブタブを対象とし、同じタブの再タップ、案件詳細・アンケート回答画面への移動は数えない。ほかのダイアログ表示中、広告を配信しない利用者状態、画面エラー時には自動表示しない。管理画面の停止は次の表示判定から反映される。

1起動はアプリページの読み込みから再読み込みまで。起動中の回数はページごとに保持する。1日1回の起動時POPUPはブラウザー共有のデモ確認日で判定する。

## データと実装範囲

既存の設定をリセットせず、初回の読み込みでサンプル広告と表示設定を追加する。一度追加したサンプルを運用で停止・削除しても復活させない。起動時頻度の初期値は今回の追加時に「起動ごと」に変更する。

画像は既存の生成画像を規定サイズに縮小したデモ素材。インステ広告は外部広告SDKや広告ネットワークへの接続を伴わない、挙動確認用のモック。

広告頻度、表示間隔、上限、配信停止、期間外、広告なし、初回移行、画像サイズ・枚数は `mock-app/tests/overlay-ads.test.mjs` で検証する。
