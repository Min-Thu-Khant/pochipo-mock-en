# 会議記録

議事録・録音・文字起こしの原本はGoogle Driveに保存します。ここには[会議FMT](../templates/meeting.md)を使い、原本URL、決定・提案・未決、対象機能ID、反映状況を記録します。

- ファイル名：`MTG-YYYYMMDD-01.md`。同日の別会議は末尾の番号で区別する。
- 継続開催のMeet URLだけで会議を識別せず、開催日時と原本のファイルIDを残す。
- 会議を停止・再開して原本が複数ある場合はすべて紐付ける。
- 再取り込みでは原本IDと更新日時・内容ハッシュを確認し、同じ決定や機能を二重登録しない。
- 会議の原文を後から最新仕様に書き換えない。決定の変更は次の会議やPRDの履歴から追えるようにする。
- 未決事項には担当者・期限を付ける。決まっていない場合は未決と明記する。

実際の会議記録と自動取り込み処理はまだありません。Drive内のフォルダ整理は対象外です。アクセスできる範囲は[Driveルール](../drive-access.md)を守ります。
