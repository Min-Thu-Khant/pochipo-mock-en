# 議事録の扱い

議事録・録音・文字起こしの原本はGoogle Driveで管理します。会議単位の本文・要約ファイルはGitへ追加・プッシュしません。

議事録を読んで更新する成果物は、PRDと機能要件表（Google Sheets）のみです。PRDには仕様に必要な決定事項・提案・未決事項を区別して反映し、根拠として原本URLと必要な該当時刻を残します。変更履歴はPRDと機能要件表の更新履歴シートで管理します。

モックの修正・デプロイは別途依頼があった場合に行います。既存の会議FMTは参考用であり、取り込み時のファイル作成は不要です。

自動取り込み・自動同期は未実装です。[運用フロー](../workflow.md)と[Driveルール](../drive-access.md)に従います。
