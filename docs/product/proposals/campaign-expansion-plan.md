# キャンペーン拡張の検討案

2026-09-18。構想整理用。実装済み機能・正式仕様ではない。

## 基本構成
キャンペーンは対象アプリ、期間、対象者、公開状態、計測、告知導線を束ねる単位。ページはその見せ方、参加・成果・報酬は別の判定機能とする。1つのキャンペーンに複数のページや導線を紐付けられる構想。

## ページと施策の型
| 型 | 例 | 必要な要素 |
|---|---|---|
| 案件キュレーション | クレカ特集・旅行特集 | 案件選択、並び順、見出し、条件別絞り込み |
| 単一案件リッチLP | 1社独占・新サービス紹介 | メイン画像、特徴、使い方、条件、FAQ、案件CTA |
| 特集記事 | 比較・使い方・季節のおすすめ | 見出し、文章、画像、比較表、関連案件 |
| ブランド・広告主特集 | 1社のサービス一覧 | ブランド情報、複数案件、カテゴリ |
| 小売店特集 | 特定小売1社の商品一覧 | 小売・店舗、商品、対象期間、参加条件、レシート投稿導線 |
| メーカー・商品特集 | 1メーカーの商品を複数小売で購入 | 商品、対象小売、購入条件、レシート報酬 |
| お試し・モニター | 購入後アンケート | 定員、応募、購入・回答条件、審査 |
| ミッション | 初回利用・連続利用・回遊 | 達成条件、進捗、期限、報酬 |
| スタンプ・複数条件達成 | 複数店舗購入・複数サービス利用 | 条件集合、達成順、重複判定、完了報酬 |
| ボーナス | 期間限定増額・追加ポイント | 対象、原資、上限、承認・否認・精算 |
| 抽選・ミニゲーム | チンチロ・開発済みスクラッチ | 参加権、回数、結果、報酬、演出 |
| チャレンジ | みんなで目標達成 | 集計対象、目標、期限、成立・不成立時の扱い |
| 招待・紹介 | 友達紹介 | 紹介関係、適用条件、双方の報酬、不正対策 |
| アンケート・チャット | 回答から案件紹介 | シナリオ、回答、分岐、案件、回答後導線 |
| 来店・地域 | 店舗訪問・チェックイン | 店舗、参加判定、位置情報等の許諾、回数制限 |
| IP・季節イベント | コラボ週間 | 共通キャンペーン配下に複数ページ・施策、素材利用期限 |

後半の参加・報酬を伴う型は、ページ編集だけでは成立せずネイティブ／バックエンド開発を要する。レシートは撮影・OCR・対象商品照合・重複排除・審査・付与が別途必要。

## ページ編集の初期範囲
テンプレート選択後に、メイン画像、見出し・文章、画像、案件カード／一覧、商品カード／一覧、比較表、FAQ、注意事項、CTAをブロック単位で追加・並べ替える。初期は自由HTMLを扱わない。商品ブロックはレシート基盤ができるまでは表示検証のみ。

## アイコン・素材
TOPメニューのアイコンはメニュー編集、チャレンジの共通装飾はチャレンジ設定に置く。案件固有の画像はNACS側の管理責務を確認する。素材ライブラリを共通で持ち、各編集画面から選択・アップロード・プレビュー・既定へ戻す操作を用意する構想。
役割ごとに寸法・比率・形式・容量・背景要件を定義する。必要なら通常／選択中の素材を分ける。適用先アプリ、共通からの上書き、IP利用期限・監修状態を管理する。アイコンアップロードは今回未実装。

## 段階
1. 現行案件キュレーションに、単一案件LPと記事テンプレートを追加する。
2. 対象アプリ・掲載期間・告知バナーをキャンペーンとして統合し、複製・プレビュー・予約・停止・計測を共通化する。
3. 開発済みのミッション・ゲーム等を接続する。
4. レシート基盤の開発後に、小売・メーカー・商品特集と審査・報酬を接続する。

公開対応版、終了ページ、案件終了・欠品、予算上限、参加済みユーザーの精算、素材利用期限を別途具体化する。

## 2026-09-18 モック実装
3種のページ選択、見出し・文章・画像・FAQ・比較表・注意事項・案件CTAのブロック追加／並べ替え／削除、編集時・保存後プレビューを追加。記事は案件なしでも作成可能、単一案件LPは1案件のみ。
TOPメニューとチャレンジ共通アイコンは正方形PNG/JPEG/WebP、2MB以下をアップロードし、プレビュー・既定へ戻す操作が可能。通常／選択時の別画像と素材ライブラリは未実装。
新しい共通・アプリ別の保存先は引き続き実アプリへ未接続。既存デモの保存先を使う場合はアプリ側の画像・ブロック描画に対応。レシート、キャンペーン横断の公開・計測統合は後続。
