# 開発会社への引き渡し

[引き渡しFMT](../templates/handoff.md)をコピーし、`v0.1.md`などのファイル名で合意した一式を記録します。発行済みの引き渡し版はありません。

## 揃えるもの

- 対象コミットとGitタグ。モック、PRD、機能一覧が同じ版に対応していること。
- モックの固定版URLまたは起動できるコード、Node.jsの要件、操作シナリオ、確認済み状態。
- 対象機能IDとPRD、優先度、対象リリース、完成条件、変更履歴。
- 機能一覧のスナップショットと元コミット。運用中の最新版シートと固定版を区別する。
- 未接続のAPI・認証・本番処理、モックとの差、見積もりに影響する未決事項と担当者・期限。

元データはGitで管理します。PDF・ZIP・一覧の書き出しなどの配布物は`output/releases/<版>/`に生成し、必要に応じて許可されたDriveへ保存します。`output/`にあるだけで納品済みとは扱いません。共有先URLと共有権限の確認結果は引き渡し記録に残します。

新しい共有先へのアクセスや保存には[Driveルール](../drive-access.md)に沿った許可が必要です。タグ作成・公開・アップロードは実際の引き渡し依頼時に行います。
