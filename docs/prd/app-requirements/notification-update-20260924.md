# F17：ベルから開くお知らせの2タブ化

更新日：2026-09-24。根拠：ユーザーの「キャンペーン／お知らせに分けたい」という依頼。

目的：注目のAF案件・キャンペーンと、不具合・アップデートなどの運営情報を区別して確認できるようにする。

## 画面と達成条件

- ベルを押すと「キャンペーン」「お知らせ」の2タブを表示する。最初はキャンペーンを選択する。
- キャンペーンでは注目のAF案件とキャンペーン情報を、公開日の新しい順（同日は掲載優先度順）に表示する。タップで案件・公開中の特集へ進む。
- モックでは既存のcampaign／recommend枠と通知文のある枠を使用する。recommend枠は「激アツAF案件」として表示する。金額・還元率は現在の案件条件を使う。新しい自動ランキングや高還元判定は導入しない。
- 掲載期間外、停止、未解禁・対象外の案件を除く。特集は公開期間と対象案件の存在を確認する。
- お知らせでは不具合・復旧、アップデート、メンテナンス情報を表示する。本文を開き、一覧へ戻れる。広告の配信対象条件に左右されない。
- タブはクリックと左右矢印・Home・Endキーで選択でき、選択状態を明示する。各一覧が空の場合は案内を表示する。
- 表示・本文の閲覧では報酬を付与しない。

## モックと本番の境界

モック状態：実装済み。運営情報は架空のサンプルであると画面内に明記する。本番の投稿API・運営情報の入稿管理・実際のプッシュ配信は今回実装していない。実画面・キーボード操作はブラウザー操作環境の不具合により未確認。

ローカル実装：`mock-app/notifications.js`、`mock-app/notifications.css`。検証：`mock-app/tests/notifications.test.mjs`。これらのモック変更は今回のPRD共有には含めない。
