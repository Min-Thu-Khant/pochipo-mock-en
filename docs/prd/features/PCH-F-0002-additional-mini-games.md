### 2026-10-09 おみくじとゲーム選択のモック

- 依頼：フッターを「ミニゲーム」にして、サイコロゲームとおみくじを選ぶ一覧を追加。
- 反映：#home/minigames が一覧、#home/minigames/dice と #home/minigames/omikuji が各ゲーム。李さん版のおみくじ筒・運勢の紙・運勢別演出を使用。
- 試作用ルール：既存チンチロの設定テーブル・動画条件を利用し、回数（最大1日3回）と未受取結果はゲーム別に保持する。おみくじの原資・確率・報酬・共通上限・個別停止設定は本番未決のまま。今回の試作では既存設定の停止・日次上限も両ゲームに適用される。
- 完成条件：片方の抽選・再挑戦・受取が他方の残回数や当たりを変更しない。再読込しても保持する。異なるゲームの結果IDや受取済みIDでは付与しない。日替わりで各回数が回復する。残回数があるゲームが1つでもあれば、ミニゲームの利用可能通知を維持する。
- 履歴：ユーザー依頼に基づくローカル4173の追加。仕様状態・Phase・本番採用時期は変更しない。
