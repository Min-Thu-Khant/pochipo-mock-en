# アフィリエイト成果の受け取り

> **このドキュメントの責務**: アプリからは見えないサーバー側の処理（バッチ・スケジュール実行・非同期処理）の観測可能な振る舞いを定義する。「深夜に残高が変わるのはバグか」に spec だけで答えられる状態にする。
>
> - 実装基盤（ジョブスケジューラ・キュー技術・ワーカー構成）は書かない
> - 処理が適用するルールの本体は domains/ が正。リンクで参照し、書き写さない
> - 「ユーザーから見える影響」セクションは必須。観測不能な場合も「ユーザーからは観測不能」と明記する（未検討と区別するため）

## 1. 概要

[NACS](../integrations/nacs.md) がアフィリエイト案件の成果（CV）を**承認**したとき、その通知を受け取って、成果に応じたポイントを**付与予定**として登録する。付与予定から保有ポイントへの確定は運用者の審査を経て行われる（[ポイント履歴](../domains/point-history.md)）。

---

## 2. トリガー

- NACS からの「成果承認」の通知が届いたこと。成果の**発生**（判定中）と**否認**の通知は受け取っても処理しない
- 時刻起動ではない。承認された成果ごとに個別に実行される

---

## 3. 処理内容

1. 通知から、対象ユーザー（外部ユーザー識別子）、成果、案件の情報、SUR 案件なら達成した段階を読み取る
2. 成果の報酬額（円）を、案件の還元設定と報酬上限から算出する（[アフィリエイト案件](../domains/affiliate.md) の「3.7」）。**0 円以下なら何も登録せず終了する**
3. 対象ユーザーが存在しない、または退会済み・無効なら何も登録せず終了する
4. 報酬額（円）を **1 円 = 100 ポイント** でポイントに換算し、付与予定として登録する
   - ポイント履歴の見出しは、定額の成果なら「案件を達成して獲得」、定率（購入額に対する割合）の成果なら「お買い物をして獲得」
   - 履歴の説明は案件名。SUR 案件の段階に対する成果は「【段階の条件】案件名」
   - 付与予定の登録時点で有効期限の目安を持つが、確定時に再計算される（[ポイント履歴](../domains/point-history.md)）
5. 審査担当が見るための成果情報（成果 ID・報酬の種別・注文金額・報酬額・案件名・成果日時）を付与予定に添える

---

## 4. 再実行安全性

- **同じ成果に対するポイントは 1 回だけ登録される。** 同じ通知が重複して届いても、処理が途中で失敗して再実行されても、二重に付与予定が増えることはない
- **SUR 案件は段階ごとに独立して 1 回。** 同じ成果でも段階が異なれば別の付与予定として登録される。同じ段階の通知が重複しても 1 回
- 「0 円以下」「ユーザーなし・無効」で終了した通知は、再送されても同じ結果になる（登録されない）

---

## 5. 失敗時の挙動

| 項目 | 内容 |
|---|---|
| リトライ | ポイント登録の失敗など一時的な失敗は自動で再試行する。通知の形式不正・報酬設定の不整合（上限の種別と値が合わない等）は再試行せず記録して破棄する |
| 通知 | 破棄された通知と再試行の枯渇は監視で検知する |
| 手動対応 | 破棄された成果は自動では復元されない。成果 ID を手掛かりに運用でポイントを付与する<!-- 要確認: 破棄された成果を手動で付与する運用手順（どの admin 機能で行うか）が未定義。https://github.com/ca-media-poi/poikatsu-spec/issues/208 --> |

## 6. ユーザーから見える影響

| タイミング | ユーザーから見える変化 |
|---|---|
| 正常実行時 | [マイページ](../screens/my-page.md) の付与予定ポイントと [ポイント履歴](../domains/point-history.md) の付与予定に、成果分のポイントが加わる。合算ポイントも同時に増える。**保有ポイントには増えない**（審査で確定した時点で保有へ移る）。[マイ案件画面](../screens/affiliate-my-affiliates.md) の「承認」への表示切り替えは本ジョブとは独立に NACS の状態で決まるため、承認タブに載る方が先になることがある |
| 失敗・遅延時 | マイ案件では「承認」なのに付与予定ポイントが増えない状態になる。一時的な失敗は再試行で解消する。破棄された成果は運用で付与されるまで反映されない |
| 0 円の成果・無効ユーザー | 何も変化しない（マイ案件の「承認」表示だけが残る） |

問い合わせの一次回答: 「承認済みなのにポイントが増えない」は、(1) 付与予定に載っているか（載っていれば審査待ち）、(2) 載っていなければ成果の承認から通知の反映までの遅延か、破棄された成果か、の順で確認する。
