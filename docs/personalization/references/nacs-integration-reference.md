# NACS（案件配信サービス）連携

> **このドキュメントの責務**: 外部サービスへの依存内容と、相手障害時のタメルコの振る舞いを定義する。障害当日に全員が最初に読む文書として、平時に書いておく。
>
> - 先方仕様は**転記しない**。必ず先方ドキュメントへのリンクにする（先方が変更すると転記は乖離するため）
> - タメルコ側のフォールバックの詳細（メンテナンス画面の発動条件・エラー表示等）は domains/ / screens/ が正。リンクで参照する
> - 認証情報・接続先などの秘匿情報は書かない

## 1. 依存内容

NACS は、複数の ASP（アフィリエイトサービスプロバイダ）の案件を束ねてチャネル（＝タメルコ）へ配信し、クリックの計測と成果（CV）の受け付け・承認・通知を行う社内の案件配信サービス。**タメルコは案件の実データ（一覧・詳細・報酬額・成果状況）を自前で持たず、すべて NACS から取得する。** タメルコ側が持つのは「どの画面にどのグループを出すか」（[案件画面設定](../admin/affiliate-screen.md)）だけである。

| タメルコの機能 | 依存内容 | 関連 spec |
|---|---|---|
| 案件一覧の表示 | グループに紐づく案件一覧コードで案件を検索し、端末の OS と「インストール案件の解禁状態」で絞り込んだ一覧を取得する | [アフィリエイト案件](../domains/affiliate.md) の「3.3」/ [API 意味論](../apis/affiliate.md) の `FetchAffiliates` |
| 案件詳細の表示 | 案件 1 件の詳細と、そのユーザーの成果状況を取得する | 同「3.4」/ `GetAffiliate` |
| チャレンジ（クリック計測） | NACS が発行するクリック URL にタメルコが署名を付けて返し、ユーザーの外部ブラウザで開く。以降の ASP への遷移・成果の紐づけは NACS が行う | 同「3.5」/ `GetAffiliateClickURL` |
| マイ案件（成果一覧） | ユーザーの成果（CV）を状態別に取得する | 同「3.6」/ `FetchMyAffiliates` |
| 成果承認によるポイント付与 | NACS が成果を承認したときの通知を受け取り、付与予定ポイントを登録する | [アフィリエイト成果の受け取り](../jobs/affiliate-conversion.md) |

NACS への接続にはチャネルの識別子と署名鍵を用いる。接続設定が欠けている場合はサーバーが起動しない（案件機能だけの縮退運転はしない）。

## 2. 相手障害時の振る舞い

**NACS の障害は案件（一覧・詳細・チャレンジ・マイ案件）と成果によるポイント付与に波及し、案件以外のポイント獲得・交換・認証には波及しない。** 案件の表示は画面のセクション単位で失敗するため、ホーム・ためトクの他のセクションは表示され続ける。

| 障害モード | タメルコの振る舞い（ユーザーから見える結果） | 波及範囲 |
|---|---|---|
| 一覧取得がエラーを返す・応答しない | `FetchAffiliates` が `ERROR_TYPE_INTERNAL` で失敗する。各画面はセクション単位のエラーと再読み込み導線を出す（[ホーム画面](../screens/home.md) / [ためトク画面](../screens/tametoku.md) / 案件一覧系の各画面） | 案件一覧 |
| 詳細取得がエラーを返す・応答しない | `GetAffiliate` が `ERROR_TYPE_INTERNAL` で失敗し、案件詳細画面がエラー表示になる。案件が存在しない場合の応答（`ERROR_TYPE_NOT_FOUND`）とは区別される | 案件詳細 |
| 成果照合がエラーを返す | 案件詳細・マイ案件が `ERROR_TYPE_INTERNAL` で失敗する（詳細は成果状況を含めて 1 回の呼び出しで返すため、案件情報だけを返す縮退はしない） | 案件詳細・マイ案件 |
| クリック URL の元になる情報が取得できない | `GetAffiliateClickURL` が失敗し、チャレンジできない。ブラウザは開かない | チャレンジ |
| 成果通知が遅延・停止する | 承認済みの成果に対する付与予定ポイントの登録が遅れる。マイ案件の状態表示は NACS の値をそのまま見るため、**マイ案件では「承認」なのにポイントが付与予定に載っていない**時間が生じる。通知が再開されれば追いつく（[アフィリエイト成果の受け取り](../jobs/affiliate-conversion.md)） | 成果によるポイント付与 |
| 成果通知が重複して届く | 同じ成果に対するポイントは 1 回だけ登録される | なし |
| 完全停止 | 案件に関する全画面がエラー表示になり、チャレンジもできない。成果の承認・通知も止まる。案件以外の機能（歩数・動画・アンケート・交換・認証）は使える | 案件全般 |

いずれの障害モードでも、タメルコ側で案件データをキャッシュして表示し続けることはしない（鮮度は「3.」）。

## 3. 制約・先方仕様

| 制約 | 内容 | 先方ドキュメント |
|---|---|---|
| 案件 ID は NACS が発行する | タメルコの案件 ID は NACS の識別子をそのまま使う。ディープリンク（[アプリスキーム](../domains/app-scheme.md) の `affiliate`）に埋める ID もこれ | <!-- 要確認: NACS のドキュメント所在が不明（ca-media-nantes/nacs） --> |
| 案件の存在確認は取得時に行う | 存在しない案件・配信終了した案件の詳細取得は「見つからない」として返る。一覧に含まれていた案件が詳細取得時に消えていることがある | 同上 |
| クリック URL の署名には有効期限がある | 署名は発行時刻を含み、**発行から前後 30 秒**しか有効でない。取得したらすぐに開く必要があり、保持して後から開くことはできない | 同上 |
| 一覧は OS で絞り込める | 案件は対応プラットフォーム（iOS / Android / Web）を持ち、一覧取得時にリクエスト元の OS で絞り込む。詳細は絞り込まず、非対応かどうかをフラグで返す | 同上 |
| インストール案件のフィルタ | 一覧取得時に「インストール案件を除く」指定ができる。解禁条件はタメルコ側のルール（[アフィリエイト案件](../domains/affiliate.md) の「3.2」） | 同上 |
| 報酬はマージン計算済みの値で返る | 報酬率・報酬額はタメルコ向けに計算済みの値として返る。タメルコはこれを表示単位（円・ポイント）へ換算するだけで、率の再計算は行わない | 同上 |
| 成果通知は承認イベントのみ消費する | NACS からの通知には成果の発生・承認・否認があるが、タメルコがポイント登録に使うのは**承認**だけ。発生・否認はマイ案件の状態として NACS から都度取得する | 同上 |
| 成果の状態は NACS が正 | 判定中・承認・否認と各日時は NACS の値をそのまま表示する。タメルコ側で状態を上書き・遅延させない | 同上 |
| ASP はタメルコから見えない | どの ASP の案件かはタメルコの振る舞いに影響しない。ASP 側の承認・否認は NACS を経由してのみ届く | 同上 |

## 5. 用語

| 用語 | 定義 |
|---|---|
| NACS | 複数の ASP の案件を束ねてチャネルへ配信し、クリック計測と成果の受け付け・承認・通知を行う社内サービス |
| ASP | アフィリエイトサービスプロバイダ。広告主の案件と成果を管理する外部事業者。タメルコは直接連携しない |
| チャネル | NACS における配信先の単位。タメルコは 1 つのチャネル |
| 案件一覧コード | NACS 側で案件の集合に付けた識別コード。タメルコの案件グループはこのコードを 1 つ持つことで案件一覧と結びつく |
| CV（コンバージョン） | ユーザーが案件の成果条件を達成したこと。NACS 上で発生 → 承認または否認の状態を持つ |
| クリック URL | チャレンジ時に外部ブラウザで開く、成果計測の起点となる URL |
