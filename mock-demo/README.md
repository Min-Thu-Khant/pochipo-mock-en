# mock-demo：連動デモ（管理画面 × NACS × アプリ）

管理画面または NACS（左。切り替え可）とアプリ（右）を 1 画面に並べ、運用側の操作がアプリに即時反映される様子をプレゼンするためのページ。すべて同一オリジンの iframe として読み込み、同じ localStorage を共有する。

- 起動：リポジトリのルートで `npm start` → http://localhost:4173/mock-demo/
- 左の管理画面は直接操作できる。下のシナリオボタンは代表的な操作を 1 クリックで実行し、管理画面・アプリをそれぞれ該当画面へ移動して、見るべき箇所を説明する
- シナリオ：最上部バナーの差し替え／動画リワードの単価変更／ミッション報酬の変更／ホームのカテゴリタブを絞る（`home_tabs`）／ゲームタブの広告差し替え（カテゴリ広告）／アンケート還元率／チャレンジ達成／テキストバナー追加／NACS：新案件の配信・報酬変更・配信停止・成果承認→付与予定・通知の重複・通知障害（オレンジの番号）／審査で確定／初期化
- 「シナリオを隠す／表示」で説明パネルを閉じ、2 画面だけにできる

公開版（claude.ai のアーティファクト）では、各モックを about:blank の iframe に書き込んで同一オリジンにしている（`?mode=artifact` でローカルでも同じ方式を再現できる）。
